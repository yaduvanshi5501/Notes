# ☁️ Hyperscalers and Azure AI

## ☁️ What are Hyperscalers?

**Hyperscalers** are large cloud providers that offer powerful infrastructure for building and running AI applications.

### Examples

- Amazon Web Services (AWS)
- Microsoft Azure
- Google Cloud Platform (GCP)

### Why are Hyperscalers Important?

- 🚀 **Elastic Scalability** – Increase or decrease resources as needed.
- ⚡ **Specialized Hardware** – GPUs, TPUs, and custom AI chips for faster AI processing.
- 🔒 **Enterprise Services** – Secure, managed AI services with global availability.

---

# 🤖 What is Azure AI?

**Azure AI** is Microsoft's cloud platform for building, deploying, and managing AI-powered applications.

It provides ready-to-use AI services and tools for developers and enterprises.

### Core Components

| Service | Purpose |
|---------|---------|
| **Azure OpenAI Service** | Access GPT models for chat, summarization, and content generation. |
| **Azure Cognitive Services** | APIs for Vision, Speech, Language, and Decision AI. |
| **Azure AI Search** | Enables Retrieval-Augmented Generation (RAG) and semantic search. |
| **Azure Machine Learning** | Train, deploy, and manage custom ML models. |
| **Azure AI Foundry** | Unified platform for managing AI models and workflows. |

---

# ❓ Why Does AI Need Hyperscalers?

Modern AI models require massive computing power.

Hyperscalers provide:

- 🖥️ Thousands of GPUs for training and inference.
- 💰 Pay-as-you-go pricing (OpEx) instead of buying expensive hardware.
- 🌍 Global infrastructure for low-latency AI applications.
- ⚡ Faster deployment using managed AI services.

# 🦙 What is Ollama?

**Ollama** is an **open-source tool** that allows you to run **Large Language Models (LLMs)** directly on your local machine without relying on cloud services.

It provides a simple API, making it easy to integrate local AI models into applications such as **Spring AI**.

---

## ✨ Key Features

- 💻 Runs LLMs locally on your computer.
- 🔒 Keeps your data private (no internet required after model download).
- 🔌 Provides a REST API for easy integration.
- 🤖 Supports popular open-source models like:
  - Llama
  - Mistral
  - Gemma
  - Phi
  - DeepSeek
  - Qwen

---

## 🎯 Why Use Ollama?

- No API key required.
- Better privacy since data stays on your machine.
- Works offline after downloading the model.
- Easy to use with Spring AI for local AI development.
