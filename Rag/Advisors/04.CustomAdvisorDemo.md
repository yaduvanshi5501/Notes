# 📚 Custom Advisor Demo – Input Sanitization & Output Post-Processing

> **Objective:** Learn how to create and use Custom Advisors in Spring AI to intercept requests before they reach the LLM and responses after they are generated. This demo demonstrates request sanitization, response enhancement, advisor chaining, and execution order.

---

# 🎯 Learning Objectives

After completing this demo, you will understand:

- How to implement your own `CallAdvisor`
- How to modify user input before the LLM call
- How to modify the LLM response after generation
- How multiple advisors execute together
- How advisor ordering works
- How to protect sensitive information before sending it to an external LLM

---

# 🤔 Why This Demo?

Enterprise AI applications often handle sensitive information such as:

- Aadhaar numbers
- PAN numbers
- Credit card numbers
- Bank account numbers
- Phone numbers

Sending this information directly to an external LLM may violate privacy or security policies.

Similarly, AI responses may also contain sensitive information that should be masked before returning it to the user.

Custom Advisors solve both problems by intercepting requests and responses automatically.

---

# 🏗 Demo Overview

The demo contains **three REST endpoints** demonstrating different Custom Advisor scenarios.

### 1. Input Sanitization

- Intercepts the user request
- Detects Aadhaar numbers
- Masks sensitive digits
- Sends only sanitized data to the LLM

---

### 2. Output Post-Processing

- Allows the LLM to generate a response
- Intercepts the response
- Masks sensitive values
- Appends token usage metadata

---

### 3. Advisor Chaining

Executes multiple advisors together:

- InputSanitizationAdvisor
- OutputPostProcessorAdvisor
- SimpleLoggerAdvisor

Demonstrates that execution depends on `getOrder()`, not registration order.

# Scenario 1 – Input Sanitization

## Purpose

Prevent Personally Identifiable Information (PII) from reaching the LLM.

---

## What Happens?

User enters:

```text
My Aadhaar number is 1234-5678-9012
```

Advisor detects the Aadhaar number using a regular expression.

Original:

```text
1234-5678-9012
```

Sanitized:

```text
XXXX-XXXX-9012
```

Only the sanitized prompt is forwarded to the LLM.

---

## Why Is This Important?

Benefits:

- Protects user privacy
- Prevents accidental PII leakage
- Enforces enterprise security policies
- Keeps controllers free from security logic

---

# Scenario 2 – Output Post-Processing

## Purpose

Modify the AI response before returning it to the client.

---

## What Happens?

After the LLM generates the response:

- Sensitive values are masked
- Token usage information is added

Example:

```text
Original Response

Your Aadhaar number is XXXX-5678-9012
```

Enhanced Response:

```text
Your Aadhaar number is %%%%-XXXX-9012

Tokens:
Prompt = 28
Completion = 20
Total = 48
```

---

## Why Add Token Usage?

Token information helps with:

- Cost monitoring
- Performance analysis
- AI usage auditing
- Observability

# Scenario 3 – Advisor Chaining

This endpoint demonstrates multiple advisors working together.

Registered order:

```text
OutputPostProcessorAdvisor

↓

InputSanitizationAdvisor

↓

SimpleLoggerAdvisor
```

Actual execution order:

```text
InputSanitizationAdvisor (1)

↓

OutputPostProcessorAdvisor (5)

↓

SimpleLoggerAdvisor (10)
```

This proves that Spring AI ignores registration order and always executes advisors according to `getOrder()`.

---

# InputSanitizationAdvisor

## Responsibility

Runs before the LLM.

Responsibilities:

- Read user prompt
- Detect Aadhaar numbers
- Replace sensitive digits
- Create a new Prompt
- Create a new ChatClientRequest
- Forward request using `nextCall()`

---

## Important Concepts

### Prompt is Immutable

A Prompt cannot be modified directly.

Instead,

```text
Original Prompt

↓

Create New Prompt

↓

Create New ChatClientRequest

↓

Forward Request
```

Spring AI uses immutable objects for safety.

---

# OutputPostProcessorAdvisor

## Responsibility

Runs after the LLM.

Responsibilities:

- Read response
- Mask sensitive data
- Extract token usage
- Append metadata
- Build new ChatResponse
- Return modified response

---

## Why Build a New Response?

`ChatResponse` is immutable.

Therefore:

```text
Original Response

↓

Modify Content

↓

Create New ChatResponse

↓

Return New Response
```

# Best Practices

- Never send sensitive PII directly to external LLMs.
- Perform input sanitization before invoking the model.
- Use post-processing to mask sensitive output.
- Preserve metadata when creating a new `ChatResponse`.
- Keep each advisor focused on a single responsibility.
- Use meaningful `getOrder()` values.

```
package com.infy.controller;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.client.advisor.SimpleLoggerAdvisor;
import org.springframework.web.bind.annotation.CrossOrigin;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import com.infy.advisors.InputSanitizationAdvisor;
import com.infy.advisors.OutputPostProcessorAdvisor;

@RestController
@RequestMapping("/api")
@CrossOrigin
public class AdvisorController {

    // Logger runs for every request created from this ChatClient
    private final ChatClient chatClient;

    public AdvisorController(ChatClient.Builder builder) {

        this.chatClient = builder
                .defaultAdvisors(
                        SimpleLoggerAdvisor.builder()
                                .order(10)
                                .build())
                .build();
    }

    // Demonstrates request preprocessing
    @PostMapping("/chat-with-input-sanitization")
    public String chatWithInputSanitization(

            @RequestParam(defaultValue =
                    "My Aadhaar number is 1234-5678-9012. What is my masked Aadhaar?")
            String userPrompt) {

        return chatClient.prompt()
                .user(userPrompt)
                .advisors(new InputSanitizationAdvisor())
                .call()
                .content();
    }

    // Demonstrates response post-processing
    @PostMapping("/chat-with-output-post-processing")
    public String chatWithOutputPostProcessing(

            @RequestParam(defaultValue =
                    "My Aadhaar number is 1234-5678-9012. What is my Aadhaar number and its format?")
            String userPrompt) {

        return chatClient.prompt()
                .user(userPrompt)
                .advisors(new OutputPostProcessorAdvisor())
                .call()
                .content();
    }

    // Demonstrates advisor ordering
    @PostMapping("/chat-with-all-advisors")
    public String chatWithAllAdvisors(

            @RequestParam(defaultValue =
                    "My Aadhaar is 1234-5678-9012. What is the capital of India?")
            String userPrompt) {

        return chatClient.prompt()
                .user(userPrompt)

                // Registration order doesn't matter.
                // Execution depends on getOrder().
                .advisors(
                        new OutputPostProcessorAdvisor(),
                        new InputSanitizationAdvisor())

                .advisors(
                        SimpleLoggerAdvisor.builder()
                                .order(10)
                                .build())

                .call()
                .content();
    }

}
```

# InputSanitizationAdvisor.java
```
package com.infy.advisors;

import org.springframework.ai.chat.client.ChatClientRequest;
import org.springframework.ai.chat.client.ChatClientResponse;
import org.springframework.ai.chat.client.advisor.api.CallAdvisor;
import org.springframework.ai.chat.client.advisor.api.CallAdvisorChain;
import org.springframework.ai.chat.prompt.Prompt;
import org.springframework.core.Ordered;
import org.springframework.stereotype.Component;

import lombok.Builder;
import lombok.NoArgsConstructor;
import lombok.extern.log4j.Log4j2;

@Component
@Builder
@NoArgsConstructor
@Log4j2
public class InputSanitizationAdvisor implements CallAdvisor, Ordered {

    @Override
    public String getName() {
        return "InputSanitizationAdvisor";
    }

    // Runs before every other custom advisor
    @Override
    public int getOrder() {
        return 1;
    }

    @Override
    public ChatClientResponse adviseCall(
            ChatClientRequest request,
            CallAdvisorChain chain) {

        String original = request.prompt()
                .getUserMessage()
                .getText();

        log.info("Original Input : {}", original);

        // Mask Aadhaar before sending it to the LLM
        String sanitized = original.replaceAll(
                "\\b(\\d{4})[-]?(\\d{4})[-]?(\\d{4})\\b",
                "XXXX-XXXX-$3");

        log.info("Sanitized Input : {}", sanitized);

        // Prompt is immutable, so create a new Prompt
        Prompt sanitizedPrompt =
                request.prompt().augmentUserMessage(sanitized);

        // Preserve everything except the modified prompt
        ChatClientRequest sanitizedRequest =
                request.mutate()
                        .prompt(sanitizedPrompt)
                        .build();

        return chain.nextCall(sanitizedRequest);
    }

}
```

# OutputPostProcessorAdvisor.java

```
package com.infy.advisors;

import java.util.List;

import org.springframework.ai.chat.client.ChatClientRequest;
import org.springframework.ai.chat.client.ChatClientResponse;
import org.springframework.ai.chat.client.advisor.api.CallAdvisor;
import org.springframework.ai.chat.client.advisor.api.CallAdvisorChain;
import org.springframework.ai.chat.messages.AssistantMessage;
import org.springframework.ai.chat.model.ChatResponse;
import org.springframework.ai.chat.model.Generation;
import org.springframework.core.Ordered;
import org.springframework.stereotype.Component;

import lombok.extern.log4j.Log4j2;

@Component
@Log4j2
public class OutputPostProcessorAdvisor implements CallAdvisor, Ordered {

    @Override
    public String getName() {
        return "OutputPostProcessorAdvisor";
    }

    // Executes after input sanitization
    @Override
    public int getOrder() {
        return 5;
    }

    @Override
    public ChatClientResponse adviseCall(
            ChatClientRequest request,
            CallAdvisorChain chain) {

        // Execute remaining advisors and the LLM
        ChatClientResponse response = chain.nextCall(request);

        // Modify the generated response
        return postProcessResponse(response);
    }

    private ChatClientResponse postProcessResponse(
            ChatClientResponse response) {

        // Token usage returned by the model
        var usage = response.chatResponse()
                .getMetadata()
                .getUsage();

        String tokenInfo = String.format(
                "\n\n---\nTokens: Prompt=%d, Completion=%d, Total=%d",
                usage.getPromptTokens(),
                usage.getCompletionTokens(),
                usage.getTotalTokens());

        String originalContent =
                response.chatResponse()
                        .getResult()
                        .getOutput()
                        .getText();

        // Mask any sensitive number in the response
        String enhancedContent = originalContent.replaceAll(
                "[0-9]{4}-[0-9]{4}",
                "%%%%-XXXX");

        enhancedContent += tokenInfo;

        // Build a new response while preserving metadata
        ChatResponse enhancedResponse = ChatResponse.builder()
                .generations(List.of(
                        new Generation(
                                new AssistantMessage(enhancedContent))))
                .metadata(response.chatResponse().getMetadata())
                .build();

        log.info("Original Response : {}", originalContent);
        log.info("Enhanced Response : {}", enhancedContent);

        return ChatClientResponse.builder()
                .chatResponse(enhancedResponse)
                .context(response.context())
                .build();
    }

}
```
