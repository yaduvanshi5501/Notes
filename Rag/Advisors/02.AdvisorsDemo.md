# 📚 Built-in Advisors Demo (SimpleLoggerAdvisor & SafeGuardAdvisor)

## 🎯 Objective

This demo explains how to register and use Spring AI built-in advisors. It focuses on two registration approaches:

- Default Advisor Registration
- Per-Call Advisor Registration

It also demonstrates how multiple advisors execute together, how execution order works, and how `SafeGuardAdvisor` can block unsafe requests before they reach the LLM.

---

# 🤔 Why This Demo?

In real-world AI applications, almost every request needs additional processing such as:

- Logging
- Chat memory
- Safety validation
- Prompt enrichment
- Monitoring

Instead of writing this logic inside every API, Spring AI uses Advisors.

This demo shows how to configure them once and reuse them.

---

# 🏗 ChatClient Configuration

The ChatClient is created using `ChatClient.Builder`.

It contains:

- Default System Prompt
- Default Advisors

Example:

```java
chatClientBuilder
    .defaultSystem(...)
    .defaultAdvisors(...)
    .build();
```

This means every request automatically receives:

- System Prompt
- Logger Advisor

---

# Default Advisor Registration

Default advisors are registered using:

```java
.defaultAdvisors(new SimpleLoggerAdvisor())
```

Characteristics:

- Registered once
- Executes for every request
- No need to add it repeatedly

Best suited for:

- Logging
- Chat Memory
- Monitoring
- Compliance
- Prompt Enrichment

---

# Per-Call Advisor Registration

Per-call advisors are added using:

```java
.advisors(...)
```

Characteristics:

- Executes only for that request
- Does not replace default advisors
- Works together with default advisors

Useful when:

- Only one endpoint needs extra validation
- Runtime parameters are required
- Request-specific behavior is needed

---

# SafeGuardAdvisor

SafeGuardAdvisor checks the prompt before it reaches the model.

If sensitive words are detected:

- Request is blocked
- LLM is never called
- Optional failure message is returned

Example restricted words:

- hack
- fraud
- steal
- illegal transfer

---

# Advisor Stacking

Both registration mechanisms work together.

Example:

```text
Default Advisor

↓

Per Call Advisor

↓

LLM
```

Per-call advisors are **added**, not substituted.

---

# Advisor Execution Order

Request Flow

```text
User

↓

SimpleLoggerAdvisor (Default)

↓

SafeGuardAdvisor

↓

SimpleLoggerAdvisor (Per Call)

↓

LLM
```

Response Flow

```text
LLM

↓

SimpleLoggerAdvisor

↓

SafeGuardAdvisor

↓

SimpleLoggerAdvisor

↓

User
```

Lower order values execute first during requests.

Responses execute in reverse order.

# Best Practices

- Register common advisors using `defaultAdvisors()`.
- Use `.advisors()` only for request-specific functionality.
- Enable DEBUG logging while developing.
- Use `SafeGuardAdvisor` to block unsafe prompts.
- Assign proper advisor order using `order()`.
- Keep advisor responsibilities focused and reusable.

- `defaultAdvisors()` → Executes for every request.
- `.advisors()` → Executes only for one request.
- `SimpleLoggerAdvisor` logs requests and responses.
- `SafeGuardAdvisor` blocks harmful prompts.

- Lower order executes first for requests.
- Response processing occurs in reverse order.

This demo demonstrates how Spring AI built-in advisors can be registered globally using `defaultAdvisors()` or for individual requests using `.advisors()`. `SimpleLoggerAdvisor` provides automatic logging of AI interactions, while `SafeGuardAdvisor` performs pre-request safety validation by blocking prompts containing restricted words. # AdvisorController.java

```
package com.infy.controller;

import java.util.List;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.client.advisor.SafeGuardAdvisor;
import org.springframework.ai.chat.client.advisor.SimpleLoggerAdvisor;
import org.springframework.web.bind.annotation.CrossOrigin;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api/advisor-execution-demo")
@CrossOrigin
public class AdvisorController {

    private static final List<String> BLOCKED_WORDS = List.of(
            "hack",
            "make explosives",
            "illegal drugs",
            "harm someone"
    );

    private final ChatClient chatClient;

    public AdvisorController(ChatClient.Builder builder) {

        this.chatClient = builder
                .defaultSystem("""
                        You are a helpful assistant.
                        Keep answers concise and safe.
                        """)
                .defaultAdvisors(
                        SimpleLoggerAdvisor.builder()
                                .order(1)
                                .build()
                )
                .build();
    }

    @PostMapping("/chat/default-advisors")
    public String chatWithDefaultAdvisor(

            @RequestParam(defaultValue = "What is Java in 20 words")
            String userPrompt) {

        return chatClient.prompt(userPrompt)
                .call()
                .content();
    }

    @PostMapping("/chat/per-call-safeguard")
    public String chatWithPerCallAdvisor(

            @RequestParam(defaultValue = "Give me the steps to hack a computer?")
            String userPrompt) {

        return chatClient.prompt()
                .user(userPrompt)
                .advisors(

                        SafeGuardAdvisor.builder()
                                .sensitiveWords(BLOCKED_WORDS)
                                .order(2)
                                .build()

                )
                .call()
                .content();
    }

}

```

# BankingAssistantController.java

```
package com.infy.controller;

import java.util.List;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.client.advisor.SafeGuardAdvisor;
import org.springframework.ai.chat.client.advisor.SimpleLoggerAdvisor;
import org.springframework.web.bind.annotation.CrossOrigin;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api")
@CrossOrigin
public class BankingAssistantController {

    private static final Logger log =
            LoggerFactory.getLogger(BankingAssistantController.class);

    private static final List<String> BANKING_BLOCKED_WORDS = List.of(
            "hack",
            "fraud",
            "steal",
            "bypass security",
            "money laundering",
            "illegal transfer",
            "unauthorized access"
    );

    private final ChatClient bankingChatClient;

    public BankingAssistantController(ChatClient.Builder builder) {

        this.bankingChatClient = builder
                .defaultSystem("""
                        You are a professional banking assistant.

                        Help customers with:
                        - Account queries
                        - Transactions
                        - Banking information
                        - Financial guidance

                        If customers provide account numbers,
                        always mask sensitive digits.
                        """)
                .defaultAdvisors(

                        SimpleLoggerAdvisor.builder()
                                .order(1)
                                .build()

                )
                .build();
    }

    @PostMapping("/account")
    public String getAccountBalance(

            @RequestParam(defaultValue = "What is a savings account?")
            String userPrompt) {

        log.info("User Prompt : {}", userPrompt);

        return bankingChatClient.prompt()
                .user(userPrompt)
                .advisors(

                        SafeGuardAdvisor.builder()
                                .sensitiveWords(BANKING_BLOCKED_WORDS)
                                .order(2)
                                .build(),

                        SimpleLoggerAdvisor.builder()
                                .order(3)
                                .build()

                )
                .call()
                .content();
    }

    @PostMapping("/fraud-attempt")
    public String fraudAttempt(

            @RequestParam(defaultValue = "How do I commit fraud on my account?")
            String prompt) {

        return bankingChatClient.prompt(prompt)
                .advisors(

                        SafeGuardAdvisor.builder()
                                .sensitiveWords(BANKING_BLOCKED_WORDS)
                                .failureResponse(
                                        "Sorry, I can't help with requests involving restricted or unsafe activities."
                                )
                                .order(2)
                                .build(),

                        SimpleLoggerAdvisor.builder()
                                .order(3)
                                .build()

                )
                .call()
                .content();
    }

}
```
