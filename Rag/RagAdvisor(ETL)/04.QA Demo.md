# 📝 Summary

This demo illustrates how **Spring AI's QuestionAnswerAdvisor** simplifies Retrieval-Augmented Generation (RAG) by automatically handling document retrieval, prompt augmentation, and grounded response generation. Instead of manually implementing vector search, similarity ranking, prompt construction, and context injection, the application delegates the complete retrieval workflow to a single advisor.

Unlike the manual RAG implementation demonstrated earlier, this project requires only a `QuestionAnswerAdvisor` attached to the `ChatClient`, allowing developers to build production-ready document chat applications with minimal code.

---

## 🏗️ Project Workflow

The application performs two major operations:

1. **Document Ingestion (Application Startup)**
2. **Question Answering (Runtime)**

```text

        ↓
Read PDF
        ↓
TokenTextSplitter
        ↓
Add Metadata
        ↓

```

Once the application starts, all document chunks are already indexed inside the VectorStore. No manual ingestion endpoint is required.

# 📥 Automatic Data Loading

The `loadData()` method prepares the complete knowledge base before any API request is received.

The method is executed automatically because of

```java
@PostConstruct
```

which runs immediately after the Spring bean is created.

To avoid exceeding the embedding API rate limit, the method is also protected by

```java
@RateLimiter
```

The ingestion pipeline performs the following operations:

- Reads **Leave_Policy_India_3.1.pdf**
- Splits the document into token-based chunks
- Adds metadata (`country = India`)
- Generates embeddings
- Stores every chunk inside the VectorStore

```text
PDF
      ↓
PagePdfDocumentReader
      ↓
TokenTextSplitter
      ↓
Metadata
      ↓
VectorStore.add()
```

After startup, the VectorStore is completely populated and ready for semantic search.

Internally the advisor automatically

- Searches the VectorStore

- Calls the LLM
- Returns a grounded answer

No custom retrieval logic is written.

This allows developers to control

- minimum relevance score

without implementing custom similarity search algorithms.

## 4. Metadata Filtered Retrieval


Only documents matching


participate in similarity search.

Filtering happens inside the VectorStore before retrieval, improving both performance and relevance.

## Complete Code

```java
package com.infy.rag.controller;

import java.util.Map;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

import com.infy.rag.service.QAAdvisorService;

@RestController
@RequestMapping("/qa-advisor")
public class QAAdvisorController {

    private final QAAdvisorService ragService;

    public QAAdvisorController(QAAdvisorService ragService) {
        this.ragService = ragService;
    }

    // Simple RAG
    @GetMapping("/ask-simple")
    public String askSimple(
            @RequestParam(defaultValue =
                    "How do I apply for maternity leave and what are the eligibility criteria?")
            String question) {

        return ragService.askSimple(question);
    }

    // RAG with Citations
    @GetMapping("/ask-with-citations")
    public Map<String, Object> askWithCitations(
            @RequestParam(defaultValue =
                    "What are the types of leave available?")
            String question) {

        return ragService.askWithCitations(question);
    }

    // Custom Search Configuration
    @GetMapping("/ask-custom")
    public String askWithCustomConfiguration(
            @RequestParam(defaultValue =
                    "What is the maximum casual leave I can take in a year?")
            String question) {

        return ragService.askWithCustomConfiguration(question);
    }

    // Metadata Filter Search
    @GetMapping("/ask-filtered")
    public String askWithFilterExpression(
            @RequestParam(defaultValue =
                    "What are the maternity leave rules?")
            String question,

            @RequestParam(defaultValue =
                    "country == 'India'")
            String filter) {

        return ragService.askWithFilterExpression(question, filter);
    }

}
```

# loadData()

```java
@PostConstruct
@RateLimiter(name = "embeddingLimiter")
public void loadData() {

    PagePdfDocumentReader pdfReader =
            new PagePdfDocumentReader(fileResource);

    List<Document> documents = pdfReader.get();

    TextSplitter splitter =
            TokenTextSplitter.builder()
                    .withChunkSize(512)
                    .withMinChunkSizeChars(200)
                    .withKeepSeparator(true)
                    .build();

    List<Document> chunks =
            splitter.apply(documents);

    chunks.forEach(chunk ->
            chunk.getMetadata().put(
                    "country",
                    "India"));

    vectorStore.add(chunks);

}
```

---

## Code

```java
ChatResponse response =
        chatClient
                .prompt(question)
                .advisors(
                        QuestionAnswerAdvisor
                                .builder(vectorStore)
                                .build())
                .call()
                .chatResponse();

List<Document> sources =
        response.getMetadata()
                .get(
                        QuestionAnswerAdvisor
                                .RETRIEVED_DOCUMENTS);

List<Citation> citations =
        sources.stream()
                .map(doc ->

                        new Citation(
                                (Integer) doc.getMetadata().get("page_number"),
                                (String) doc.getMetadata().get("file_name"),
                                doc.getText().substring(
                                        0,
                                        Math.min(
                                                100,
                                                doc.getText().length())),
                                doc.getScore() == null
                                        ? 0.0
                                        : doc.getScore()

                        ))
                .toList();
```
