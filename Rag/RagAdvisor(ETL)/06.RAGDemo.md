# 📝 Summary

This demo demonstrates how to build a **production-grade Retrieval-Augmented Generation (RAG)** application using Spring AI's `RetrievalAugmentationAdvisor`. Unlike `QuestionAnswerAdvisor`, this implementation separates document retrieval from prompt augmentation, allowing retrieval behaviour to be customized without changing the advisor itself.

The application ingests multiple hotel policy PDFs, stores their embeddings inside a MariaDB VectorStore, and uses `RetrievalAugmentationAdvisor` together with `VectorStoreDocumentRetriever` to answer user questions with grounded, traceable responses.

# 📥 Document Ingestion

The `/ingest-pdf` endpoint prepares the knowledge base before any retrieval occurs.

During ingestion the application

- reads every hotel policy PDF
- extracts the country from the filename
- stores metadata (`source`, `country`)
- splits documents into semantic chunks
- generates embeddings
- stores all chunks in the VectorStore

```text
PDF
      ↓
PagePdfDocumentReader
      ↓
Metadata
      ↓
TokenTextSplitter
      ↓
VectorStore.add()
```

The stored metadata later enables metadata filtering during retrieval.

# 🤖 Basic Retrieval

The first API demonstrates the simplest production-ready RAG pipeline.

```text
GET /rag-advisor
```

Internally it uses

```text
VectorStoreDocumentRetriever
        ↓
RetrievalAugmentationAdvisor
```

The advisor automatically

- embeds the user question
- performs semantic search
- retrieves relevant chunks
- augments the prompt
- forwards the enriched prompt to the LLM

No manual prompt construction is required.

# ⚙️ Advanced Retrieval

The second endpoint demonstrates a customized retriever.

```text
GET /rag-advisor/advanced
```

The retriever is configured with

- `topK`
- `similarityThreshold`
- `FilterExpressionBuilder`

This allows precise control over

- retrieval quality
- retrieval quantity
- metadata-based document filtering

without modifying the advisor itself.

---

# 🏷️ Metadata Filtering

Every document receives metadata during ingestion.

Example

```text
country = India
source = Hotel_Grand_Heaven_India_Policy.pdf
```

During retrieval

```text
FilterExpressionBuilder
        ↓
country == 'India'
```

ensures that only Indian hotel policy documents participate in similarity search.

Filtering happens before vector comparison, improving both performance and retrieval accuracy.

# 📄 System Prompt

The application uses a custom system prompt that turns the model into a **Hotel Policy Advisor**.

The prompt instructs the model to

- answer only from retrieved documents
- avoid hallucinations
- admit when context is insufficient
- generate structured responses
- ask one context-aware follow-up question

This keeps every answer consistent across requests.

# 📚 DOCUMENT_CONTEXT

The application converts those documents into custom `Citation` objects containing

- filename
- text excerpt
- similarity score

This enables transparent and auditable AI responses.

# 🚀 Key Takeaways

- `RetrievalAugmentationAdvisor` provides a modular, production-ready RAG pipeline.
- PDFs are ingested using `PagePdfDocumentReader`.
- `TokenTextSplitter` creates embedding-friendly chunks.
- Country metadata is extracted from filenames and stored with every document.
- `VectorStore.add()` automatically generates embeddings and indexes documents.
- `VectorStoreDocumentRetriever` performs semantic similarity search.
- Retrieval behaviour is customized using `topK`, `similarityThreshold`, and `FilterExpressionBuilder`.
- `MessageChatMemoryAdvisor` enables stateful conversations alongside RAG.
- A custom system prompt enforces grounded answers and structured output.
- Retrieved documents are exposed through `DOCUMENT_CONTEXT`, allowing citation generation and answer traceability.
- The modular design allows retrieval strategies to be replaced without changing the advisor or application logic.



# 📄 RetrievalAugmentationAdvisor (RAAdvisor)

## 📌 Overview

`RetrievalAugmentationAdvisor` is Spring AI's **recommended advisor for building advanced RAG (Retrieval-Augmented Generation) applications**.

Unlike `QuestionAnswerAdvisor`, which is an all-in-one solution, `RetrievalAugmentationAdvisor` separates the retrieval pipeline into independent components, making it highly flexible and extensible.

It supports:

- Query Transformation
- Document Retrieval
- Prompt Augmentation
- Metadata Filtering
- Similarity Threshold
- Top-K Search
- Conversation Memory
- Source Citations

## Complete Controller

```java
@RestController
@RequestMapping("/rag-advisor")
public class RAAdvisorController {

    private final RAAdvisorService raAdvisorService;

    public RAAdvisorController(RAAdvisorService raAdvisorService) {
        this.raAdvisorService = raAdvisorService;
    }

    @PostMapping("/ingest-pdf")
    public ResponseEntity<String> loadData() {
        return ResponseEntity.ok(
                raAdvisorService.loadData());
    }

    @GetMapping
    public String answerWithRAAdvisor(
            @RequestParam(defaultValue =
                    "What time is check-in?")
            String question,

            @RequestParam(defaultValue = "cust-001")
            String conversationId) {

        return raAdvisorService.answerWithRAAdvisor(
                question,
                conversationId);
    }

    @GetMapping("/advanced")
    public Map<String, Object> answerWithAdvancedRetriever(

            @RequestParam(defaultValue =
                    "What is the cancellation policy?")
            String question,

            @RequestParam(defaultValue = "country")
            String key,

            @RequestParam(defaultValue = "India")
            String value,

            @RequestParam(defaultValue = "cust-001")
            String conversationId) {

        return raAdvisorService
                .answerWithAdvancedRetriever(
                        question,
                        key,
                        value,
                        conversationId);

    }

}
```
